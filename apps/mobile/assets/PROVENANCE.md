# Mobile asset provenance

Audit baseline: `reference/main`. Before this migration, the following 24
Mobile assets had Git blob ids identical to that reference.

## Retained external-provider assets

These three files are required interoperability assets, not LVM identity
artwork, and are intentionally retained byte-for-byte:

| Path | Reference/current blob | Classification |
| --- | --- | --- |
| `fonts/MaterialSymbolsFilled.ttf` | `4efdc98a7004737532cb35d1b47e7fd71d64f43f` | Google Material Symbols subset; provider font required by Android native-symbol rendering |
| `fonts/MaterialSymbolsOutlined.ttf` | `ecf7aa3743695e6ef26c9cbe0610dc4f6cba129f` | Google Material Symbols subset; provider font required by Android native-symbol rendering |
| `google-g.webp` | `0450c1365c66d7cabd2d42c9ca5106b9771617ae` | Google brand mark required to identify the Google sign-in action |

The Material Symbols subsets are regenerated by
`apps/mobile/scripts/build-symbol-fonts.py` from Google's upstream font under
the Apache License 2.0. The Google G is retained solely as provider
identification in the OAuth button; it is not presented as LVM-owned artwork.
